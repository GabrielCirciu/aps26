\problemname{Exoplanetary Rover SLAM}

Several autonomous planetary exploration rovers are mapping a subterranean cave system on exoplanet \texttt{Kepler-16b}.
They use a complex mapping algorithm, tracking exactly $N$ distinct geological landmarks.
The data for these landmarks is stored in a massive $N \times N$ state transition matrix.

Because the cave is subject to intense magnetic interference, the rovers' memory is prone to corruption.
%Over the last four seconds, each rover has logged four sequential transition matrices: $A$, $B$, $C$, and $D$.
Over the last phase of exploration, each rover has logged a sequence of M transition matrices: $M_1$, $M_2$, …, $M_M$.
The navigation module has just output a final state matrix $E$, claimed to represent the result of applying all transition matrices in sequence. % representing a rover's predicted environment for the next movement phase.

Before the rovers fire their thrusters to move, they must verify that the final state $E$ is mathematically sound, 
otherwise one of them may risk crashing into the cave walls.
Specifically, it must be guaranteed that the sequential application of all transitions equals the final state:
$$M_1 \times M_2 \times \cdots \times M_M = E$$

Because transmitting millions of matrix elements across the communication relay is too slow and unpredictable,
each rover transmits only the \texttt{seeds} values used to generate their respective matrices.
You, as ground control crew, must use a Pseudo-Random Number Generator (PRNG) to reconstruct the full matrices locally.

\section*{Input}

The first line contains an integer $N$ - the dimension of the square matrices.

The second line contains an integer $M$ - the number of generated matrices in the multiplication chain.

The next $M$ lines each contain a single integer - $S_i$, representing the seed used to generate matrix $M_i$.

The following $N$ lines describe the target matrix $E$. Each of these lines contains $N$ space-separated integers representing one row of the matrix.

The input format can be summarized as:

\begin{verbatim}
N
M
seed1
seed2
...
seedM
E11 E12 ... E1N
E21 E22 ... E2N
...
EN1 EN2 ... ENN
\end{verbatim}
