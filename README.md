# aps26
Project for the ITU course: Algorithmic Problem Solving (Spring 2026).

## Solved problems
The folder DP contains the solution for the kattis problem maximum subarrays which can be found [here](https://open.kattis.com/problems/maximumsubarrays).

The folder NF contains the solution for the kattis problem avoiding the apocalypse which can be found [here](https://open.kattis.com/problems/avoidingtheapocalypse).

The folder GA contains the solution for the kattis problem the giant which can be found [here](https://open.kattis.com/problems/jatten).

## Group problem 
Our own created problem can be found inside the folder problemtools/exoplanetaryroverslam. The folder contains everything from test cases, test case generators, input validator, problem statement pdf, intended solutions and wrong solutions. Inside the folder, the commands _verifyproblem_ and _problem2pdf_ from problemstools can be run.
